# smart-refrigrator-system-Iot-
An IoT Smart Refrigerator Shelf automating inventory tracking using an AI-Thinker ESP32-CAM, OV3660 lens, and a 1kg load cell sensor. A custom-trained YOLOv8 AI model identifies items with 96.8% precision. Real-time telemetry logs sync via a Node.js backend and React frontend dashboard to update a persistent cloud history ledger.
